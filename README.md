A multi-agent honeypot system that detects scams, engages scammers through 5 distinct AI personas, and extracts actionable intelligence — all in real time.

Description
When a scammer sends a message, this system:

Detects the scam type (bank fraud, UPI fraud, phishing, job scam, etc.)
Selects the best persona to engage (Uncle, Aunty, Student, TechSavvy, Worried)
Engages the scammer over multiple turns, extracting phone numbers, UPI IDs, bank accounts, phishing links, and email addresses
Reports all extracted intelligence to the GUVI evaluation callback
